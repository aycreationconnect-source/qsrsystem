Architectural Layout & Dual-Tier Topology

Understanding how the Local Billing Hub communicates with the Developer Cloud Support Platform.

Tier 1: Local POS Hub Engine Port 3000

Deployed on a local Mini-PC / Windows Terminal inside the cafe. Houses the SQLite / MySQL local database with full offline resilience. Receives table orders from waiter tablets, fires KDS events, manages raw material recipes, and prints bills.

Base URL: http://localhost:3000
Auth: Cookie (pos_jwt_token) / Bearer <JWT>
Database: MySQL / Local Database via Prisma
Tier 2: Central Developer & Support Platform Port 3001/api

Cloud portal for the software franchise vendor. Allows registering new cafe outlets, managing subscription plans (Silver, Gold, Diamond), issuing offline cryptographic HMAC license tokens, and executing franchise-level analytics.

Base URL: http://localhost:3001/api
Role: Superadmin & Franchise Controller
License Engine: Crypto HMAC-SHA256 Token Generator
